# Todo Manager (CLI)

## Description
This is a Python Command Line Todo Manager built using Object-Oriented Programming (OOP).

## Features
- Add Task
- View Tasks
- Mark Task as Completed
- Delete Task
- File-based Persistence using JSON
- Inheritance using ImportantTask class

## Technologies Used
- Python 3
- JSON
- OOP

## Project Structure

Todo Manager
- main.py
- manager.py
- task.py
- storage.py
- tasks.json

## How to Run

```bash
python main.py
```
